# AccessAgent — Universal Accessible Software Engineering Assistant

AccessAgent is an offline-first VS Code extension leveraging fine-tuned Gemma 4 to make autonomous software development accessible to everyone—including blind, deaf, mute, elderly, and student developers.

## Repository Contents
- `index.html` — Accessible Webview interface for Visual Studio Code.
- `DOC-20260427-WA0002.pdf` — Architecture whitepaper & research documentation.

## Features
- **WCAG 2.1 AA Compliant UI:** ARIA live regions and keyboard-navigable interface.
- **Offline Gemma 4 Local Model:** Zero latency, full code privacy.
- **Multi-Modal Accessibility:** Text-to-Speech integration, Socratic explanations, high contrast controls.
